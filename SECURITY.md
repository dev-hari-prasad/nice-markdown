# Security Policy

Nice Markdown is a client-side markdown editor, but security still matters. If you discover a vulnerability, please **do not open a public issue**. Instead, report it privately.

## Supported Versions

Only the latest version on the main branch receives security updates.

## Reporting a Vulnerability

If you find something that could compromise user data, expose sensitive information, or create a security risk, please reach out privately:

**Email:** webdev.byhari@gmail.com  
**GitHub:** https://github.com/dev-hari-prasad/nice-markdown

When reporting, please include:

- A clear description of the vulnerability  
- Steps to reproduce the issue  
- The expected impact  
- Any suggested fixes (if you have ideas)

I'll do my best to respond within **48 hours**.

## Security Notes

- Nice Markdown runs entirely in your browser - all processing happens locally.  
- No telemetry or tracking systems are used.  
- You have full control over where and how you run it (locally, self-hosted, or deployed).  
- Be careful with any exported files or configurations that might contain sensitive content from your markdown documents.

Thanks for helping keep Nice Markdown secure!
